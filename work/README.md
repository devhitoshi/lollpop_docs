# work/ — 汎用の一時作業場

このディレクトリは**一時的な作業ファイル**のための場所です。**中身が空であるのが正常な状態**です。

- 検討中のメモ、途中経過、実験的な出力など、まだ置き場が決まらないものを一時的に置く
- 残す価値が決まったら、しかるべきドメインへ運び出す
- 役目を終えたら削除する（過去の版として残したいものは `archive/` へ）

## 運び出し先の早見表

| 恒久化するもの | 行き先 |
| --- | --- |
| note 記事（シリーズ・単発とも） | `articles/` |
| 公演・セトリのデータ | `events/` |
| 曲に関する資料（歌詞・曲調） | `songs/` |
| メンバーに関する資料 | `members/` |
| 戦略・定点観測 | `strategy/` |
| ファン向け入口ドキュメント | `guide/` |
| 旧版・役目を終えたドラフト | `archive/` |

過去にここにあった note 記事シリーズ（歌詞考察・週刊/月刊まとめ・セトリ白書）は
`articles/` へ、集計CSVは `events/` へ、定点観測は `strategy/` へ移設済みです。
