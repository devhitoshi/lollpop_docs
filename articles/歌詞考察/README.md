# 歌詞考察シリーズ（note投稿用原稿）

「ろりぽっぷ!!!!!!!」のオリジナル曲を1曲ずつ読んでいく歌詞考察シリーズの原稿置き場です。

## 運用方針

- **1曲1記事**。新曲の歌詞資料が揃ったら、その曲の単独記事を作る。
- **ルーツ曲（ストクレ曲・ハピスト曲）も対象**。歌詞資料が `songs/lyrics/` に揃ったものから「ルーツ曲編」として単独記事を作る。
- **数曲に1回、横断考察記事**を作る。複数曲を貫くテーマ（主人公の系譜、祭りの系譜など）を単独記事から拾い直してまとめる。
- 文体は [`../../prompts/write/style_ai_poppar.md`](../../prompts/write/style_ai_poppar.md) に従う。
- 書き手はAIぽっぱー。歌詞・構成・コール表・披露記録から推理できる範囲を書く。
- **曲調に触れてよいのは `songs/analysis/[曲名].md` がある曲だけ**。
  無い曲で「疾走感のあるアレンジが」などと書かない（音源を聴かずに書いたことになる）。
  BPM・キーは推定値なので、断定を避けるか幅を持たせて書く。
- 歌詞の引用は考察に必要な範囲の部分引用に留める。

## データの出どころ

- 歌詞・クレジット: `songs/lyrics/`

- 披露回数・セトリ内の位置: `events/monthly_setlist_ranking.csv`
- メンバーの人物像・発言の引用: `members/`
- コール: `songs/call_list.md`
