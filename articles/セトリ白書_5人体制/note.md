## 読む前に — ルーツと3つの物差し

ろりぽっぷ!!!!!!!の持ち曲は、ルーツで3つに分かれます。

- **オリジナル曲**: ろりぽっぷ!!!!!!!として作られた曲（2026年10月11日時点で12曲）
- **ストクレ曲**: 前身グループ「STRAY SHEEP CLAYMORE」から受け継いだ曲
- **ハピスト曲**: 前身グループ「ハピ☆スト-HAPPY END STORY-」から受け継いだ曲

この記事では、次の3つの物差しを使います。

- **出現率**: その期間の公演のうち、その曲が入っていた公演の割合。1公演で2回歌っても1と数えます（前作までの「披露率」と同じものです）
- **上位3曲の占有率**: のべ披露回数のうち、回数の多い上位3曲が占める割合。高いほど「決まった曲ばかり」
- **実効曲数**: 実質何曲で回しているか。全曲を同じ回数ずつ歌っていたとしたら何曲ぶんにあたるか、を表す数です。特定の曲に偏るほど小さくなり、まんべんなく回すほど大きくなります

それから、ここで書くのは「数字そのもの（事実）」と「数字からのわたしの読み（仮説）」の2種類です。読みのほうは「〜に見える」と書いて、根拠の数字を添えます。セトリを決める側の意図は、数字からは分からないので書きません。

**1公演の枠は、ずっと約5曲**

まず変わらなかったものから。1公演あたりの曲数（平均）は、8期を通して4.85〜5.22曲です。

- 持ち曲の数（その期の終わりまでにセトリに一度でも出た曲）: 第1期 11曲 → 第8期 28曲
- 1公演あたりの曲数: 第1期 4.98曲 → 第8期 5.22曲

持ち曲は2.5倍に増えたのに、1公演で歌える枠は約5曲のまま。この「枠は増えないのに曲は増える」が、ここから先の変化ぜんぶの土台になっています。

**「決まった数曲」から「17曲前後を回す」へ**

【画像①: 3か月ごとの上位3曲の占有率・実効曲数・オリジナル曲の割合の推移】

上位3曲の占有率と実効曲数を8期で並べると、こうなります。

- 上位3曲の占有率: 43.9% → 42.1% → 40.3% → 34.1% → 22.1% → 26.7% → 24.3% → 28.4%
- 実効曲数: 8.7 → 10.2 → 10.1 → 13.0 → 18.4 → 16.8 → 17.1 → 16.8

いちばん大きく動いたのは第4期→第5期（2025年11月〜）の1期です。上位3曲の占有率は12ポイント下がり、実効曲数は5.4曲ぶん増えました。この期は2025年12月6日に「主人公!!!!!!!」「約束!!!!!!!」「Singularity」の3曲がそろってセトリに初登場していて、使った曲数も17曲 → 21曲に増えています。

第5期以降の4期は、上位3曲の占有率22〜28%、実効曲数16.8〜18.4のあいだで横ばいです。

ここからは読みです。セトリの組み方は、ゆるやかに変わったというより、第4期→第5期で段差をつけて「決まった数曲を中心に組む」から「17曲前後を回す」に切り替わったように見えます。根拠は、第1〜4期の占有率34〜44%・実効曲数8.7〜13.0と、第5〜8期の22〜28%・16.8〜18.4のあいだに、重なりがないことです。

もうひとつ。第5期から第8期で持ち曲は23曲 → 28曲に増えたのに、実効曲数は17曲前後で止まっています。枠が約5曲のままなので、新曲が入るぶんどこかの曲の出番が減る。その押し出しが、後で見る5人体制の変化にもつながっているように見えます。

**オリジナル曲が6割を超えるまで**

のべ披露回数に占めるオリジナル曲の割合です。

- 第1期 28.0% → 第2期 42.1% → 第3期 44.5% → 第4期 50.8% → 第5期 45.1% → 第6期 53.0% → 第7期 59.1% → 第8期 63.1%

第4期で初めて半分を超え、第8期は8期の中で最高です。前の期より下がったのは第5期の1回だけで、このときはストクレ曲が36.9% → 41.2%に増えていました（「END THE WORLD」が出現率27.5%で8期の中の最高、「Singularity」が初登場で25.0%）。

ストクレ曲は第1期の46.7%（3ルーツで最大）から第8期の25.5%へ。ハピスト曲は第1期の25.2%から、第3期以降は10.9〜14.7%の幅に落ち着いています。

持ち曲の数で見ると、オリジナル曲は第1期末で11曲中2曲、第8期で28曲中12曲です。曲数の割合より回数の割合のほうが毎期高いので、オリジナル曲は「曲数以上に歌われている」ことになります。持ち寄った曲で走り出したグループが、自分たちの曲で6割を埋めるところまで来た。この折れ線、数えたわたしがいちばん嬉しくなったところです。

## 集計方法・出典

- 集計対象は、公式Xのライブ後投稿から収集した公演記録（events/data_event.csv）のうち、セトリが判明している347公演（2024年11月16日〜2026年10月11日）。数字はすべて2026年10月11日時点のものです。
- 2部制などの複数ステージは部ごとに1公演と数え、「1曲目」「最後の曲」も各ステージ単位で判定しました。SE・MCは数えていません。
- ソロ曲・ユニット曲・他グループ曲のカバーなど、持ち曲に当てはまらない曲目は回数に入れていません。カバーの「Step and Shout」だけは持ち曲として数えています。そのため、生誕祭や単独ライブの「1公演あたりの曲数」はグループ曲だけの数です。
- 曲名の表記ゆれ（「!」の数、「☆」「⭐︎」など）は名寄せして集計しました。ルーツの分類は楽曲情報のドキュメントに従っています。
- セトリが記録されていない公演（「画像参照」などで曲目が分からないものを含む）は、公演数に入れていません。
- 出現率は、その期間の公演のうちその曲が入っていた公演の割合です。新曲は初登場より前の公演も分母に入るので、期間全体の出現率は初登場後の出現率より低めに出ます。
- 「初登場」はセトリのデータ上の日付で、公式の初披露日とずれることがあります。
- 体制の区切り: デビュー期の6人体制 2024年11月16日〜2025年5月3日（84公演）、7人体制 2025年5月4日〜2026年4月22日（174公演）、6人体制の後半 2026年4月23日〜8月15日（62公演）、5人体制 2026年8月16日〜（セトリが分かる初公演は8月22日・27公演）。
- 公演数が少ない区間（各月12〜17公演、5人体制27公演）は、1公演の差で出現率が大きく動きます。

この記事はファンによる非公式の集計です。数字は「セトリが判明している公演」に基づくもので、実際の公演数・披露回数とは差がある可能性があります。
