note の本文を最後に合わせた日）の正はここ。** 公開したらここに追記する。スターターパック README の表は
このファイルへのリンクに置き換える。

## 使い方

- 新しい記事を公開したら行を追加する（シリーズ・記事ファイル・URL・公開日・最終同期日を埋める）。
- 既存記事の原稿を書き替えて note に貼り直したら「最終同期日」を更新する。
- `check_stale.py` は「最終同期日」（無ければ「公開日」）から `--days`（既定60日）以上経った行を表示する。
  URL が空欄の行は「未記録」として別に数える。
