# note_embed_x — X の URL をまとめて埋め込みカードにする

原稿（Markdown）を note にまとめて貼ると、単独行の X の URL は**ただのリンクのまま**になる
（note は「空の段落に URL を 1 本ずつ貼る」か「＋→埋め込み」のときだけカードにする）。
1 記事に 10〜30 本あると手作業では回らないので、ブックマークレットで一括変換する（2026-09-29〜）。

## 使い方

1. 初回だけ: Chrome でブックマークを新規作成し、名前を「X埋め込み」、URL 欄に `bookmarklet.txt` の中身（`javascript:` から最後まで）を貼る
2. 原稿を note の編集画面にまとめて貼る
3. ブックマークバーの「X埋め込み」を押す。右下に進み具合が出る（1 本 1〜2 秒）
4. 「◯ / ◯ 本を変換しました」と出たら「下書き保存」を押す

- 変換するのは、段落に X の投稿 URL だけが書かれた行。**「出典」「編集メモ」の見出しより後ろは触らない**（出典の URL はリンクのまま残す）
- 途中で止まったら、止まった URL が表示される。その行を手で「＋→埋め込み」にしてから、もう一度押す（変換済みの行は飛ばす）
- 何度押しても壊れない（変換対象が無ければ「ありませんでした」と出るだけ）

## 仕組みと保守

`embed_x.js` が本体。URL の段落を空にしてから、その段落へ URL の貼り付けイベントを送る。
手で貼るのと同じ経路なので、できるカードは手作業の埋め込みと同じ構造になる（シルバーウィーク2026 の下書きで 28 本を確認）。
note の編集画面が変わって動かなくなったら `embed_x.js` を直し、`python build_bookmarklet.py` で `bookmarklet.txt` を作り直す。

市販の同種ツール（Tampermonkey のユーザースクリプト・¥500）もあるが、中身は同じ操作の自動化なので自前で持つ。
