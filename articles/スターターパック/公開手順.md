# 公開手順（note）

3本を新規投稿し、既存記事は残したまま冒頭に誘導を足す（2026-09-02 決定）。
note 側はすべて手作業。**この順番で進めること**（URLが確定しないと張れないリンクがあるため）。

## 1. 3本を新規投稿する

`01_入門編.md` → `02_メンバー編.md` → `03_現場編.md` の順に投稿する。各記事で:

1. 冒頭の HTML コメント（入稿メモ）を**削除する**
2. 見出し画像に `img/0N_header.png` を設定する
3. 本文の `【画像①: 〜】` を、入稿メモの対応表どおりに `img/` の PNG へ差し替える
4. 本文の `【Xポスト埋め込み】` `【Xポスト埋め込み: 3代目アー写】` の行を削除し、
   直後の X の URL を**単独行のまま**にする（note が自動で埋め込みカードにする）
5. `（※公開後にURLを挿入）` は、次の記事を投稿してから埋める

**投稿したら、下の表に URL を記録すること。**

| （2）メンバーを知って、推しを決める | | |
| （3）ライブに行って、特典会で話す | | |

## 2. 3本の相互リンクを埋める

本文中の `（※公開後にURLを挿入）` に、上の表の URL を入れる。
