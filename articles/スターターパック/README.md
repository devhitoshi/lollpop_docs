## 運用方針

- 読者は**ろりぽっぷを知らない人**。週刊・月刊まとめ（既存ファン向け）とは前提が違う。
- 文体は [`prompts/write/style_ai_poppar.md`](../../prompts/write/style_ai_poppar.md) の
  「事実は淡々と」の原則には従うが、**限界オタク口調は使わない**。
  初見の読者を置いていかないため、既存の `単発/note_starter_pack.md` と同じ落ち着いたトーンで書く。
- note の制約により**表組みは使わず、見出しは2階層まで**。リンクは裸URLで単独行に置く（カード展開）。
- **メンバーの写真は本文に貼らない。** 事務所（FLAP entertainment）の著作物なので、
  顔を見せたい箇所は**X投稿の埋め込み**で代替する。出典が明示され、権利の問題も出ない。
  数字や手順は自作のPNG図版（`img/`）に逃がす。
- 3本はそれぞれ単独で流入するので、**各記事の冒頭に非公式の断りと基準時点、末尾に相互リンク**を置く。
