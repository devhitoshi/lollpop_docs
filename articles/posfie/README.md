# posfie まとめ

[posfie](https://posfie.com/)（Togetter 系の X ポストまとめサービス）に出すまとめの素材。
**このディレクトリに置くのは「どのポストを、どの順で、どんなコメントを添えて貼るか」の設計図**で、
posfie 上の実体は別にある（公開したら下の表に URL を書く）。

作り方は `.claude/skills/posfie-summary`。

## note の週刊まとめとの住み分け

| | note 週刊まとめ | posfie |
| --- | --- | --- |
| 見せるもの | 出来事を再構成した読み物 | ポストの並びそのもの |
| 本文 | 自分の文章が主 | 引用が主、コメントは短く |
| 向く回 | 毎週の定期更新 | 生誕祭・ワンマンなど投稿が集中した回 |
| 元データ | 同じ（`work/x_fetch/` と `events/data_event.csv`） | 同じ |

同じ週を両方で出してよい。事実関係は週刊まとめの原稿を流用して、二度調べ直さない。

## 決まりごと

- 貼るのは **X の埋め込みだけ**。画像を直接貼らない（`pbs.twimg.com` の直リンクも不可）
- 文体・禁止表現は note と同じ [`prompts/write/style_ai_poppar.md`](../../prompts/write/style_ai_poppar.md) に従う
- 外した投稿は理由とセットで素材 md の末尾に残す
