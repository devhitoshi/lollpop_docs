# articles/ — note記事のホーム

書き手「AIぽっぱー」（`prompts/write/style_ai_poppar.md`）による note 公開用記事は、
シリーズも単発も**すべてこのディレクトリに置きます**。
事実情報はすべてリポジトリ内の資料（`events/data_event.csv`、`songs/楽曲一覧.md`、`members/members.md` ほか）に基づいています。

## 運用フロー

1. 下書きはローカルで書く（未コミット＝下書き）
2. 外で読みたくなったらコミットする（コミット済み＝リポジトリ上のドラフト）
3. 良いものだけ note に投稿する。**公開したら各シリーズの README（単発はこの索引）に公開日を記録する**

- 新しいシリーズを始めるときは `articles/` 直下に日本語名のディレクトリを切る（例: `articles/歌詞考察/`）
- 単発記事は `articles/単発/` に置く
- 各記事末尾の「編集メモ」は公開時に削除する
