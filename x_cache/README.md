# x_cache/

`.claude/skills/x-account-fetch/scripts/fetch_egosearch.py` が使う、エゴサーチ（周囲の反応）の
永続ローカルキャッシュです。

## なぜこのディレクトリがあるか

エゴサーチ（キーワード検索）はアカウント別検索よりノイズ比率が高く、同じ期間を何度も検索し直す
機会が多い（週刊まとめ→月刊まとめで期間が重なる、記事を書き直すときに見直すなど）。
twitterapi.io は呼び出しごとに課金されるため、**一度取得したクエリ結果は使い回す**ことでコストと
待ち時間を節約する。

## なぜコミットしないか

取得した投稿は他人の著作物。`.claude/skills/x-account-fetch/SKILL.md` の規約どおり
「再配布・データセット公開・生成モデルの学習利用はしない」ため、本文を含む生データを
Gitにコミットすることはできない。このディレクトリ自体は（このREADMEを除いて）`.gitignore` 対象。

`work/`（基本は空にする運用）とは違い、こちらは**意図的に永続化**する場所。掃除しないこと。

## 構成

```
x_cache/
  egosearch/
    {since}_{until}/           例: 2026-08-25_2026-09-01
      2-1_基本形.jsonl
      2-2_カタカナ英字.jsonl
      2-3_メンバー名.jsonl
      2-4_固有名詞_{語}.jsonl
      2-5_画像動画.jsonl
```

クエリ単位（ファイル単位）でキャッシュする。同じ`{since}_{until}`・同じクエリラベルの
ファイルが既に存在すれば、`fetch_egosearch.py` はAPIを叩かずそこから読む。
`--refresh` で強制的に取り直せる。

記事に使うのは、ここから人間かLLMがノイズ判定した後の一部（採用したものだけ）。
コミットしてよいのは記事本文に書いた引用と出典URLのみ。
