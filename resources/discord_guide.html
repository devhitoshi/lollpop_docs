DISCORD

Discord から、
記事と動画をつくる

スレッドを立てて、話しかけるだけ。
台本を書き、直し、動画にするところまで、ぜんぶチャットで進みます。

RULES

覚えることは、3つだけ

🧵

1スレッド＝1つの仕事

別の動画・別の記事は、必ず新しいスレッドを立てる。 同じスレッドの中では、前の話を覚えたまま続きができます。

✅

ボタンが出たら押す

ファイルを書き換えるときやコマンドを実行するとき、確認のボタンが出ます。 押さないと先に進みません。

🎬

動画は、言うまで作られない

台本ができても勝手に動画にはなりません。 納得してから「動画にして」と言ってください。

START

はじめかた

最初の1回だけ、少し手順があります。2回目からは1と2だけ。

1

#openacp-sessions を開く

このチャンネルが入口です。ここ以外では反応しません。

2

新しいスレッドを立てる

「🆕 New Session」のボタンを押すか、/new と打ちます。 どのフォルダで作業するか聞かれたら projects/lollpop_docs を選びます。

3

やりたいことを、そのまま書く

コマンドを覚える必要はありません。ふだんの言葉で大丈夫です。 スレッドの名前は、最初のひとことから自動でつきます。

最初の返事に出てくる「ブランチ名」は控えておく

video/20260910-単独ライブ告知 のような名前が返ってきます。 時間が空いて話が通じなくなったときも、この名前を伝えれば続きから再開できます。

PATTERN A

ゼロから、台本と動画をつくる

いちばん多い流れです。台本で納得してから、動画に進みます。

1

「〇〇の動画を作るので、台本を作って」

どんな動画にしたいかを書きます。素材があるなら、その場所も添えます。

2

台本の本文が、チャットに貼られる

リンクを開かなくても、その場で全部読めます。長いときは何通かに分かれます。 あわせて GitHub のリンクも返ってきます（後から読み返す用）。

3

気になったところを、そのまま書く

「3つ目が長い」「もっと軽い言い方に」でかまいません。直したあと、 どこをどう変えたかが要約で返ってきます。

4

納得したら「これでOK、動画にして」

ここではじめて動画づくりが始まります。数分かかるので、 先に「作りはじめます」と返事が来て、できたら知らせが来ます。

5

Google ドライブのリンクが返る

スマホでそのまま再生できます。直したいところは次の節の書き方で伝えます。

PATTERN B

すでにあるものを、直してもらう

台本・記事・動画のレビューから始めるときは、どれのことかが伝わればOKです。 あとの往復はパターンAと同じ。

あなた

strategy/video/台本/F-003_リハの日の話.md をレビューして

あなた

ドライブの「20260904_くるみちゃん紹介動画」の動画、後半のテンポが遅い

返ってくるもの

作業ブランチの名前 → 直した内容の要約 → 更新後のリンク。この3つがセットで返ります。

ファイル名がわからなくても大丈夫

「先週作ったくるみちゃんの動画」のように、覚えている言い方で伝えれば探してくれます。 間違ったものを直さないよう、確認が返ってくることがあります。

EXAMPLES

言い方の見本

迷ったら、このまま真似して送ってください。

台本をたのむ

9/20 の単独ライブの告知動画を作りたい。台本を作って

型を指定する

反応集（A）の型で、8月のライブの反応を集めた動画の台本を作って

台本を直す

3つ目のブロックが長い。半分にして

動画に進む

これでOK、動画にして

動画を直す

0:12 のテロップが画面から切れてる。直して

今どうなってるか聞く

いまどこまで進んでる？

FEEDBACK

動画の直しは、時間で伝える

「あのへん」ではなく 0:12 1:05から のように、動画の先頭からの経過時間で伝えてください。そこがいちばん速く直ります。

伝わりやすい

「0:12 のテロップが切れてる」
「1:05 から音が大きい」
「0:30 の写真を別のものに」

伝わりにくい

「後半がなんか違う」
「テロップ全体を直して」
「もっと良い感じに」

作り直した動画は、別の名前で届きます

_v2 のように名前が変わります。スマホに残っている古い動画と 見分けがつくようにするためです。最新かどうか迷ったら、いちばん新しいリンクを開いてください。

TROUBLE

うまくいかないとき

返事が来ない

確認のボタンが出たまま止まっていませんか。上にスクロールして探してみてください。 ボタンは10分で自動的にキャンセルされるので、その場合はもう一度お願いし直します。

まったく反応がない

スレッドの中で話しかけているか確認してください。チャンネルに直接書いても反応しません。 それでも無反応なら、管理者（オーナー）に連絡を。PC側が止まっている可能性があります。

ドライブのリンクが開けない

「アクセス権が必要です」と出たら、フォルダの共有がまだです。管理者に自分の Google アカウントを伝えてください。

話が通じなくなった

時間が空くと、それまでの流れを忘れていることがあります。 最初の返事に出ていたブランチ名を伝えると、続きから戻れます。

途中でやめたい

/cancel と打つと、そのスレッドの作業が止まります。

GO

まずは1本、頼んでみる

うまく言えなくて大丈夫です。ざっくり書いて、返ってきたものを見てから直していくほうが、 結果的に速く終わります。
