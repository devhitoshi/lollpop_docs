# コール表画像の要件

SNS に載せるコール表画像（`img/call_sheet_<色>.png`）を、別の曲でも同じ品質で作るための要件。
2026-09-04 に「未完成ヒロイン」で作り込んだときの決定と、その理由を残す。
スキルにはしていないので、作るときはこの文書を読んでから `build_call_sheet.py` を実行する。

- コールの内容の正: [`songs/call_list.md`](../songs/call_list.md)（**画像側で内容を書き換えない**）
- デザインの正: [`design.md`](../design.md)
- 実行環境の注意: [`CLAUDE.md`](../CLAUDE.md)「実行環境の注意」

## 作りかた

```bash
# 1. フォントを入れる（コンテナは使い捨てなので毎セッション必要）
bash resources/install_capture_font.sh

# 2. HTML を生成（--song を変えれば別の曲）
python3 resources/build_call_sheet.py --song 未完成ヒロイン

# 3. 画像に書き出す
python3 resources/capture_call_sheet.py
```

リモート環境では Playwright を入れて Chromium を指定する:

```bash
pip install playwright
PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers python3 resources/capture_call_sheet.py \
  --chromium /opt/pw-browsers/chromium-1194/chrome-linux/chrome
```

## 新しい曲を作るとき

1. **`songs/call_list.md` にその曲のコールが入っているか確認する。** 「新体制のため確認中」だけの曲は画像にしない。
2. **`build_call_sheet.py` の `BLOCKS` にその曲のかたまりを定義する。** 曲の構造そのものなので曲ごとに書く。

   ```python
   "曲名": [
       ("1番", ["イントロ", "Aメロ", "Bメロ", "サビ", "間奏"]),
       ("2番", ["2Aメロ", "2Bメロ", "2サビ", "Cメロ"]),
       ("ラスト", ["2間奏", "3Bメロ", "ラスサビ", "アウトロ"]),
   ],
   ```

   - 間奏は**次のかたまりの頭**に置く。次に来るメロやサビへの助走だから（未完成ヒロインの 2間奏 = 行！く！ぞー！のMIX はラスサビの助走なのでラスト側）。
   - 定義に無いパートは直前のかたまりに入り、**実行時に警告が出る**。行は落ちないので、警告が出たら `BLOCKS` を直す。
   - 定義しなくても動く（1つのかたまりとして出る）が、区切りが無いぶん読みにくい。
3. 生成して、**画像を目で見る**。折り返しの位置、かたまりの分量の偏り、はみ出しを確認する。
4. 公開前に「公開前チェック」（下記）を通す。

## 画面の作り

1曲まるごとが1枚。上から順に:

```
🍭 ろりぽっぷ!!!!!!! 非公式コール表 ・ YYYY年M月D日時点     ← 出どころと時点
曲名                                                    ← 104px
コール表                                                 ← 40px

1番                                                     ← かたまり（アクセント色の文字）
  イントロ            ← 1段目: 曲の構成      36px・グレー
  メンバーコール       ← 2段目: やること      48px
  ● あみ → ● くるみ   ← 3段目: メンバーパート 54px・太字・担当カラーのドット
  …
2番
  …
ラスト
  …

ここに書いたのは一例です。…                               ← 注記
```

### 1パート3段（曲の構成 → やること → メンバーパート）

種類の違う情報を1行に混ぜない。横に並べると1行に収まって縦は短くなるが、読みにくい。

- 3段目（メンバーパート）が一番大きい。担当カラー付きの名前が先に目に入る。
- **パートの1行目は必ず大きく**する。長い説明文でも小さくすると、イントロや2間奏のように文で書かれたパートだけ弱く見える。
- 2行目以降の補足（コツ・但し書き）は 38px に落とす。目を留めたときに読めればいい。
- 短い合図（`SHORT` = 20文字以下）と長い説明の区別は文字数で機械的に決めている。

### かたまりの区切り

**スキマ＋アクセント色の文字**。塗りの帯にすると区切りのほうが主役に見えるのでやらない。

### メンバーパート

- `songs/call_list.md` で `あみ→くるみ` のようにメンバー名だけが並んでいる行を、担当カラーのドット付きで描く。`歌パートおまゆ` も拾う。
- 地の文に出てくる名前（「まうの指示に従う」など）はドットを付けない。資料のまま文字で出す。
- 担当カラーの正は [`members/members.md`](../members/members.md)、色の値は `design.md`。

### 書き下す

**中身が同じパートも「〜と同じ」で参照させない。** イントロ・間奏・アウトロが同じ内容でも、そのつど全部書く。読み手はその場で分かるべきで、前に戻らせない。

## 決めた値

| 項目 | 値 | 理由 |
| --- | --- | --- |
| カード幅 | 1800px | 横が広いと折り返しが減り、文字を大きくしても全体は縦に短くなる |
| 余白 | 上下150px / 左右140px | 地の色を周りに残す |
| 曲名 | 104px | |
| 曲の構成 | 36px・グレー | 見出しなので本文より落とす |
| やること | 48px | メンバーパートより一段小さく |
| メンバーパート | 54px・太字 | 一番大きい＝一番先に目に入る |
| 補足 | 38px | |
| 出典・注記 | 32px | |
| 書き出し倍率 | 1.5倍 | 2倍だと高さが8000pxを超え、X の上限（8192px）に迫る |
| 出力 | 約2700×6600 | 幅2700あれば SNS には十分（X の表示は最大2048px幅） |

比率はだいたい 1:2.4。縦長になるが、**スマホでは縦画像も画面の幅いっぱいで表示される**ので文字は小さくならない。

## 色

白・ベージュ・ピンク・紺の4色を同時に書き出し、そのつど選ぶ。`--colors navy` で絞れる。

- **ベージュと紺は `design.md` の4面（白・ブラッシュ・プラム黒・ピンク）に無い色。** この画像用のバリアントとして `PALETTES` に持たせている。**採用する色が決まったら `design.md` に足す。**
- 紺（暗い面）ではメンバーカラーを明るい方へ振る。濃い赤・緑のままだと面に沈んでドットが読めない。`design.md` の「暗帯ではアクセントを明るい側へ反転する」に倣ったもの。
- 白いドット（まな）は、明るい面では輪郭線あり・暗い面では輪郭なし。

## 公開前チェック

- [ ] **卒業したメンバーの名前が残っていないか。** `songs/call_list.md` には、ぽっぽ♪ポジティブ！！のCメロ（`まう→ひめ→なつ`）と始まりの宴!!!!!!!の2Aメロ（`歌パートおひめ`）に、卒業した2人（朝香・なつみ）が残っている（2026-09-04時点）。画像にする前に更新する。
- [ ] **描画に使われたフォントが Noto Sans JP か。** `capture_call_sheet.py` が確認して中断するが、他の方法で撮るときは自分で確認する。入れずに撮ると中国語フォントの字形になる。
- [ ] **画像が切れていないか。** ビューポートがカードより狭いとはみ出して切れる。切れた画像も寸法だけは正しいので、出力サイズでは気づけない（実際に見逃した）。`capture_call_sheet.py` は撮る前に収まっているか確認する。
- [ ] 曲名・非公式・時点・注記が入っているか（画像だけが出回っても出どころが分かるように）。

## やってみて却下した案

同じ失敗を繰り返さないために残す。

| 案 | 却下の理由 |
| --- | --- |
| 横長1枚（16:9）に全部入れる | SNS では画像が幅いっぱい（スマホで約390px）に縮むので、本文が4px相当になって拡大しないと読めない |
| 1曲を3枚（1番/2番/ラスト）に割る | 1曲のコール表がSNS上で散らばって追えない。保存もされない |
| 4:5 に収めるために文字を詰める | 4:5 は切り取られない比率だが、13パートを入れると文字が小さくなりすぎる。縦に伸ばしても文字は小さくならないので、伸ばすほうを選んだ |
| 繰り返しを「イントロと同じ」に畳む | 縦は縮むが、読み手が前に戻ることになる |
| かたまりを塗りの帯で区切る | 区切りのほうが主役に見える |
| 「やること」とメンバーパートを1行に流す | 縦は縮むが、種類の違う情報が同じ行に混ざって読みにくい |

## 文面のルール

- **「まわりに合わせる」ことを勧めない。** 書いてあるのはあくまで一例。感じたままに声を出しても、身体を動かしても、なにもしなくてもいい、という立場で書く。
- 非公式（ファン有志のまとめ）であることを必ず入れる。
