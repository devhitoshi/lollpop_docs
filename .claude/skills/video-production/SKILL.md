# 縦型動画の制作（台本 → 動画 → 納品）

台本を書き、承認を受けてから動画にし、Google Drive に置いて URL を返すまで。
**動画の中身をどう作るか**（型・構成・禁止事項）の正は [`strategy/short_video_playbook.md`](../../../strategy/short_video_playbook.md) と
[`strategy/video/formats/`](../../../strategy/video/formats/)。このスキルが決めるのは**段取りと成果物の置き場**だけ。

## 段取り

```
台本を書く → コミット → 本文＋URL を返す ─┐
                                          ├→（承認）→ 動画化 → Drive → URL を返す →（指摘）→ 作り直し
      ←── 指摘 ← 直す ← 再コミット ←──────┘
```

**台本の承認前に動画化を始めない。** 動画化は「これでOK」「動画にして」のような**利用者からの明示的な指示だけ**を起点にする。
レンダリングは数分かかるので、着手を先に返してから始める。

既存の台本・動画のレビューや修正から始まることもある（対象はファイルパスか Drive 上の名前で指定される）。
その場合は現物を読むところから入り、以降の往復は同じ。

## 台本

- 置き場は `strategy/video/台本/<型ID>-<連番>_<タイトル>.md`（例: `F-003_リハの日の話.md`）。**リポジトリに入れる**（Discord から URL で辿れるようにするため）。
- 雛形は `strategy/video/scripts/00_台本テンプレート.md`（G 型は `00_G台本テンプレート.md`）。導入の言い回しは `00_導入ブロックの言い回し20通り.md`、読みの指定は `読み辞書.tsv`。
- 型（A〜G）の選択と本数の方針は `strategy/video/README.md` の 2026-09-07 判断記録。迷ったら型を先に確認して返す。
- 文体と禁止語は [`prompts/write/style_ai_poppar.md`](../../../prompts/write/style_ai_poppar.md) 末尾の「使わない言葉・使い方」。**台本・テロップ・字幕・キャプション・ハッシュタグすべてに効く。**
- 本文はチャットに貼る（2000 文字を超えたら分割）。併せて `gh browse --no-browser --branch <ブランチ> strategy/video/台本/<ファイル>` で URL を取って返す。

## 素材

素材はリポジトリ内（`work/x_media/` など）か Google Drive にあり、**利用者からはパスか Drive 上の名前で指定される**。
名前だけ言われたら現物を特定してから使う。見つからないときは推測で代用せず、どれを指しているか聞く。

**自分で探しに行くときは `x-media-collect` を使う。**許諾の記録（`data/x/media_permissions.md`）に「OK」がある素材だけを落とす、
クレジットを必ず入れる、という制約はそのまま効く。

## 動画化

| 型 | ツール | 実行できる場所 |
| --- | --- | --- |
| A・B・C・E（素材の連結・テロップ・引用カード） | `python3 .claude/skills/x-media-collect/scripts/make_vertical.py --spec <spec.json>` | どこでも（ffmpeg） |
| F・G（メンバーエピソード・掲示板掛け合い） | 別リポジトリ `lollpop_video`（Remotion＋VOICEVOX） | **ローカルの Windows のみ。** GitHub に無いのでクラウドでは動かない |
| D（写真の連結） | どちらでも | |

出力は `work/` の下に書く（`.gitignore` 済み）。**動画・音声・画像などのバイナリはコミットしない。**

## 納品（Google Drive）

1. `G:\マイドライブ\claude-work\<yyyymmdd>_<タスク名>\` に**ファイルをコピーする**（Drive for Desktop が同期する）。
   MCP 経由のアップロードは使わない（base64 でトークンを食い、画質も落ちる）。
2. 同期が終わったら `search_files`（`title = '<ファイル名>'`）で `fileId` を取り、
   `https://drive.google.com/file/d/<fileId>/view` を返す。
3. **`strategy/video/台本/納品メモ.md` に 1 行追記してコミットする**（日付・台本ファイル・動画ファイル名・Drive URL・版）。
   台本と同じディレクトリに置くのは、あとから「この台本で作った動画はどこか」を辿れるようにするため。

利用者が Drive を開けない場合は、フォルダの共有設定が抜けている。共有は `SETUP_DISCORD.md` の手順で一度だけ行う。

## 指摘への対応

動画への指摘は**タイムコード**で来る（「0:12 のテロップが切れてる」「1:05 から音が大きい」）。
タイムコードは**書き出した動画の先頭からの経過時間**。spec の区間（segment）に読み替えて直す。
どの区間のどのパラメータを変えたかを、直したあとチャットで要約する（利用者は差分を見ない）。

作り直したら Drive に**新しいファイル名で**置く（`_v2` のように）。同名で上書きすると、
利用者の手元にキャッシュされた古い動画と区別がつかなくなる。納品メモも 1 行追記する（既存行は消さない）。
