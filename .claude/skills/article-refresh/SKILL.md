# 公開済み note 記事の更新

公開中の note は編集も差し替えも手作業。差分検知 → 一次データとの突き合わせ → 改稿 → レビュー →
貼り替え手順書、を毎回同じ型で回す。

## 前提

- 公開 URL と最終同期日の正は [`articles/公開一覧.md`](../../../articles/公開一覧.md)。
  スターターパック README の記事一覧表はそのままだが、URL・最終同期日は公開一覧.md 側を見る。
- 実行頻度はイベント駆動（メンバーの加入・卒業／新曲リリース／コール表の更新／ワンマン等の大きな公演／
  料金・会場ルールの変更）。定期実行ではないので、見落とし防止に `check_stale.py` を使う。

## 手順

1. **対象を選ぶ**

   ```bash
   python .claude/skills/article-refresh/scripts/check_stale.py
   ```

   `articles/公開一覧.md` を読み、最終同期日から時間が経った記事を一覧する（既定60日。`--days` で変更、
   `--json` で機械可読）。イベント駆動のきっかけ（メンバーの加入・卒業など）があるときはそちらを優先し、
   このコマンドは見落とし防止の補助にする。

2. **公開中の本文を取得し、リポジトリの原稿と差分を出す**

   WebFetch で `articles/公開一覧.md` の note URL から公開中の本文を取得し、リポジトリ側の対応原稿
   （公開一覧.md の「記事ファイル」列）と突き合わせる。**公開後にリポジトリ側だけ直した箇所（＝貼り替え漏れ）
   を先に拾う。** 差分検知は改稿の前に必ず行う（一次データの更新より前に、単純な貼り替え漏れが無いか確認するため）。

3. **一次データと突き合わせて古い記述を列挙する**

   `events/data_event.csv`・`songs/楽曲一覧.md`・`members/members.md`・`songs/call_list.md` と本文を
   突き合わせ、古くなっている記述（メンバー体制、曲数、コール、料金・会場ルールなど）を列挙する。

4. **更新範囲・出力先を決める**

   AskUserQuestion で、どこまで直すか（全面改稿か部分修正か）と、貼り替え手順書の置き場
   （`claude-work/<yyyymmdd>_<タスク名>/`）を確認する。

5. **改稿する**

   [`prompts/write/style_ai_poppar.md`](../../../prompts/write/style_ai_poppar.md) の文体・表現規約
   （末尾「使わない言葉・使い方」を含む）に従う。**メンバー写真は本文に直貼りしない**
   （`pbs.twimg.com` などの直リンク不可。X 埋め込みか自作図版に差し替える）。

6. **`article-review` を通す**

   `.claude/skills/article-review` の手順（機械チェック → 読み取り専用エージェント）で ERROR を解消する。

7. **貼り替え手順書を作る**

   [`templates/貼り替え手順.md`](./templates/貼り替え手順.md) を元に、`claude-work/<yyyymmdd>_<タスク名>/`
   に貼り替え手順書を作る。note 側は手作業なので、**そのまま貼れる文面・投稿順・URL依存関係**を書く
   （複数記事にまたがる場合、後続記事のURLが確定してから前の記事に貼る、など）。

8. **公開一覧を更新する**

   `articles/公開一覧.md` の該当行の「最終同期日」を更新する。実際に note へ貼るのはオーナーの手作業なので、
   貼り替えが完了した報告を受けてから更新する。

## 注意

- **note 側の貼り替えは手作業。** このスキルは改稿と手順書までを担い、実際の貼り替えは行わない。
- **画像はメンバー写真を直貼りしない。** X 投稿の埋め込みか自作図版（`img/`）にする
  （[`prompts/write/style_ai_poppar.md`](../../../prompts/write/style_ai_poppar.md) 末尾「使わない言葉・使い方」）。
- **`guide/starter_pack.md` より `articles/スターターパック/` が正**（2026-09-03 に反転）。
  スターターパックを更新するときは `articles/スターターパック/` 側を直し、`guide/starter_pack.md` にも
  同じ内容を反映する。
- 素材に無いことは書かない。話をつなぐための推測で埋めない。分からないことは編集メモか積み残しへ。
- 卒業メンバーは在籍時の事実だけ。卒業後の活動・私生活には触れない。
