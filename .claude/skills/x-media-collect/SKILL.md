# 縦型動画の素材索引

告知・周知を縦型動画でやるための素材探し。**このスキルが作るのは索引（メタデータ）であって、素材そのものではない。**
実際に使える素材かどうかは、下の「素材の3つの層」で判断する。

## 素材の3つの層（`guide/rules.md` の撮影ルールに基づく）

| 層 | 使えるか | 根拠 |
| --- | --- | --- |
| **自分で撮ったもの** | 使える。**これが主力** | 主催・単独ライブは「静止画、動画全編『○』」「動画、静止画の掲載は可能です。その際ハッシュタグやメンションのご協力お願いします」。対バンは静止画が全編可、**動画は指定曲のみ** |
| **公式・メンバーの投稿** | 運営に確認してから | グループ・事務所の著作物。ファンの告知に使うなら一声かけるのが筋。掲載歓迎の文脈があるので話は通りやすい |
| **他のファンの投稿** | 本人の許諾が要る | 撮影者に著作権がある。索引で相手を特定して、個別に依頼する |

X の `allow_download_status`（索引の `dl_flag`）は **X 上で保存ボタンが出るかどうか**であって、利用許諾ではない。混同しない。

## 手順

1. **索引を作る**

   ```bash
   python3 .claude/skills/x-media-collect/scripts/build_media_index.py --since 2026-08-01 --until 2026-08-31
   ```

   `data/x/media_index_<since>_<until>.csv` ができる（追跡する。URL と数値だけで画像は含まない）。
   取得データが無ければ先に `x-account-fetch` / `x-egosearch`、消えていれば `x-data-sync pull`。

2. **縦型の候補を絞る**

   ```bash
   python3 ... --orientation 縦 --type video --source 公式・メンバー
   ```

   `orientation` は元画像の縦横比から。縦型（9:16）にそのまま載る素材が見つかる。
   横型しかない見せ場は、切り出し（センター寄せ or 被写体追従）が要るので手間が別に発生する。

3. **撮影ルールの列で仕分ける**

   `撮影ルール` が「主催」の日の素材は、動画も全編撮影可・掲載可の日のもの。自分で撮った分ならそのまま使える。
   「対バン」の日の動画は指定曲のみなので、その曲だったかを確認する。**公演名からの推定なので、現物の告知で裏を取る。**

4. **許諾を取る**

   他人の素材を使うなら、`author` と `post_url` から本人に依頼する。もらえたら `data/x/media_permissions.md` に
   「誰の・どの投稿を・いつ・どういう条件で」許諾されたか記録する（口頭やDMの記憶に頼らない）。

## 縦型動画に向く素材の条件

- **縦（9:16）**。横型を切ると被写体が切れる。ライブ撮影は最初から縦で撮る
- **15〜60秒**。1曲まるごとではなく、サビ・コール・振りの見せ場だけ
- **音が使えるか**。既存曲を乗せるなら、TikTok などのアプリ内ライブラリに公式音源があるか先に確認する（`web-research`）。
  自前の音源ファイルを乗せるのは別の話になる
- **顔が寄っている**。特典会のチェキ・写メは縦型で顔が近く、告知のサムネイルに向く（`guide/rules.md`「特典会中に撮影したチェキは、SNS等へアップしていただいて問題ございません」）

## やらないこと

- 他人の投稿の画像・動画を一括ダウンロードしない。索引で候補を絞り、許諾を取ってから個別に受け取る
- 索引に画像・動画そのものを入れない（`data/x/` は追跡するので、他人の著作物を置かない）
- `dl_flag` を利用許諾の根拠にしない
