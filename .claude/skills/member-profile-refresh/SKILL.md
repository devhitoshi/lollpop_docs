# メンバーのパーソナリティデータ更新

`members/*.md` は、なりきりプロンプト由来の記述（一人称・二人称・「〜な人」）が骨組みになっていた。
2026-09-09 に**人格心理学の記述モデル（McAdams の3層）＋アイドル固有の2層**の6節構成へ改めた。
節の定義と禁止事項の正は [`members/README.md`](../../../members/README.md)。**書く前に必ず読む。**

このスキルの役割は、**数えてから読む**ことで根拠の無い人物像を書かないようにすること。

## 前提

- `work/x_fetch/<handle>.jsonl` に対象期間の投稿があること（無ければ `.claude/skills/x-account-fetch` で取得）
- **5人の被覆期間を揃える。**期間がばらつくと、そのまま「人物像の濃さの差」になる。
  揃うまで更新を見送るか、揃っている範囲だけ更新して `members/README.md` の状況を書き添える
- 1層（発信の傾向）は 1〜3ヶ月の窓で見る。4層（話題の在庫）は**長い窓**（1年〜デビュー以降）で取り、
  そのうえで最終言及日の新しいものを上に置く

## 手順

### 1. 数える（発信の傾向）

```bash
python3 .claude/skills/member-profile-refresh/scripts/profile_stats.py --since 2026-08-01 --until 2026-08-31
```

`work/x_fetch/profile_stats_<since>_<until>.md` に、メンバーごとの投稿数・時間帯・曜日・ハッシュタグ・
絵文字・メンション先・冒頭と末尾の定型句・よく出る語・伸びた投稿5件が出る。
**1層は5人の相対で書く。**「132件」ではなく「5人中最多」まで書いて意味になる。

### 2. 話題を拾う（4層・特典会用）

```bash
python3 .claude/skills/member-profile-refresh/scripts/topic_inventory.py --since 2024-11-16 --until 2026-09-09
```

`work/x_fetch/topic_inventory_<handle>_<since>_<until>.md` に、カテゴリごとの
「語・回数・頻度・初出・最終言及・注意・用例」、文脈語で拾った投稿、
そして「メンバーとのつながり」（相手・言及数・**うち私的**・使っている呼び方・最終言及）が出る。

- **これは候補であって在庫表ではない。**「注意」列（曲名・会場名との衝突）が付いたものは必ず原文を見る。
  「新宿」「渋谷」の大半はライブ会場、「ラムネ」は曲名「夏色ラムネ」
- 辞書に無い固有名詞（店名・作品名・アーティスト名）は `<details>` の文脈語ヒットから拾う。
  よく出る語が辞書に無いと分かったら `topic_inventory.py` の `CATEGORIES` に足す
- **仕事（レッスン・ボイトレ・衣装・撮影）は趣味ではない。**4層に入れず、2層（鍛えていること）へ回す
- **つながりの表は「私的」列で読む。**告知は全員に触れるので、言及の総数は仲の良さを表さない。
  関係性の断定（「仲良し」「相棒」）は本人か公式がそう言っている場合だけ書ける

### 3. 引用を集める（2層・3層）

統計では出ない。`<handle>.jsonl` を grep して原文で集める。

- **2層（動機・価値観）**: 同じ趣旨が**3回以上**出るものだけ。1回の発言は価値観ではなく、その日の気分
- **3層（自己物語）**: 経歴の事実は公式発表と `events/data_event.csv` で確定させる。
  本人がそれをどう語ったかは投稿の引用で持つ。**事実と語りを同じ文に混ぜない**
- 前身グループ期の文脈は `work/x_fetch/SSC_official_.jsonl`（STRAY SHEEP CLAYMORE 公式、2022-09〜2024-10）にある

### 4. 書く（`members/<ローマ字名>.md`）

`members/README.md` の6節構成に従う。各節の冒頭に出典行を置く:

```
> 出典: 取得した投稿の集計（YYYY-MM-DD〜YYYY-MM-DD・N件、.claude/skills/member-profile-refresh）
```

- 割合（「告知 約40%」）を書くなら統計の数から出す。感覚で書かない
- 引用は原文どおり。伸ばし棒・記号の重なり・誤字も整えない
- 末尾に**触れない話題**（体調・容姿の評価・他メンバーとの比較・卒業メンバーの現在・恋愛・居住地）を明記する
- 末尾の「観測ログ」に今回の期間・件数・更新日を積む。**前の行を消さない**（差分を追えるようにする）

### 5. 確認する

`members/members.md`（基本情報の正）と矛盾が無いか見る。
`article-review` の機械チェックは `members.md` を正として絵文字を照合するので、
担当カラーを変えるときは `members.md` を先に直す。

## 出力の扱い

`profile_stats_*.md`・`topic_inventory_*.md`・JSONL は他人の投稿原文を含む。
`work/x_fetch/` に置いたままコミットしない。リポジトリに入るのは、根拠を要約した `members/*.md` の記述だけ。
セッションの終わりに `.claude/skills/x-data-sync` で退避する。
