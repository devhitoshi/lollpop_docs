## データの構成

各ファイルは同じ並びで書かれています。

| 節 | 内容 | 出典 |
| --- | --- | --- |
| 基本情報 | 名前・読み・あだ名・担当カラー・誕生日・出身地・在籍・前所属・SNS | [`../members.md`](../members.md)（正） |
| パーソナリティ | 一人称／二人称、人物像、話し方の特徴 | 公式SNS・ライブでの発言をもとにした整理 |
| X の発信傾向 | 発信の軸／価値観／主な読み手／文体／よく使う表現 | LLM（Grok）によるポスト分析・2026年3月時点 |

## 取り扱いのルール

- **基本情報の正はルートの [`members.md`](../members.md)。** 誕生日・出身地・在籍期間などが食い違ったら
  `members.md` に合わせ、こちらを直す。
- **観測されていないことを書かない。** 「実は〇〇な一面がある」のような人物像の盛りは、
  本人の投稿・公式発表に根拠がある場合だけ。憶測で埋めない。
- **卒業したメンバーの卒業後の活動・私生活には踏み込まない。** 在籍時の事実のみを扱う。
- **体調・人間関係・運営の意図の推測は書かない。**
- **X の発信傾向は 2026年3月時点のスナップショット。** 期間が空いたら再分析して差し替える。
  分析は元ポストが根拠なので、引用した言い回しを勝手に整えない。
- **メンバー構成が変わったら全ファイルを見直す。** 現体制は5人（愛月まな／やぎくるみ／夏川茉夢／松川愛美／まう）。
