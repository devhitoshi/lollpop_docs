# メンバーが語る楽曲（お披露目時の説明）

オリジナル12曲について、メンバーが X で「どんな曲か」を語った投稿を集めた資料。
歌詞考察・全楽曲解説・動画の台本で「メンバーはこう言っている」と書くときの根拠に使う。

- 作成: 2026-10-02
- 情報源: `work/x_fetch/` の取得済みデータ（公式＋現メンバー5人、2024-11-16〜2026-10-01）。本文と、画像の ALT（説明欄）の両方を読んだ
- 抜き出し方: 初披露日の前日〜4日後の投稿を全文確認。加えて、全期間から「曲名＋説明の語（歌詞・思い・込め・振り付け など）」に当たる投稿と ALT を拾った

## 使うときの注意

- **メンバーの言葉は「歌う側の受け取り方」。作詞・作曲者の制作意図ではない。** 「〜という思いで作られた」と書かず、「◯◯は〜と語っている」と書く
- **卒業した2人（姫杏朝香・苺花なつみ）の投稿は取得していないので入っていない**（`members/README.md` の凍結方針）。〜2026年6月の曲は2人の説明が抜けている可能性がある
- 配信（TikTok・SHOWROOM）や MC で話した内容は対象外
- 引用は抜粋。絵文字・改行は省いている。記事に引くときはリンク先の原文を確認する
- ALT は取得データ上 1,000 字前後で切れているものがある（まうの長文など）

## 全体として読めること

1. **「自分を信じて前に進む」が背骨。** 乙女ロック → Unknown → 主人公 → 未完成ヒロイン → シーソーゲームと、説明の芯がほぼ同じ。違うのは力点
   - 乙女ロック: みんなと一緒に（1人じゃない）
   - Unknown: 自分の可能性を信じて（外の声は気にしない）
   - 主人公: 自分の人生の主人公は自分（好きに生きていい）
   - 未完成ヒロイン: 遠回りや間違いにも意味がある（今の自分を否定しない）
   - シーソーゲーム: 弱い自分も受け入れる
2. **「一緒にやる」ための曲が並走している。** ぽっぽ♪ポジティブ！！・メイク☆マイダンス・夏色ラムネは、意味よりも「サビを一緒に」「乾杯を一緒に」「振りを覚えて」と語られる
3. **節目ごとに「挑戦」として曲が増えている。** 2ndワンマン（2025-11）は黒衣装・新SE と合わせて「かっこいい」への幅出し。まゆは「みんなと楽しむ！お祭り騒ぎ！をメインにしてきましたが、今一人一人が活かせるものを更に魅せてく」と書いている。
   2026年夏の2曲は複数のメンバーが揃って「今までにない」と言う（かわいい方向と、エモい・チルい方向）
4. **約束!!!!!!! だけは成り立ちが違う。** メンバー7人が歌詞・振り付け・立ち位置を考えた曲で、まうは「オリジナル曲の中で1番大好き」と言い、後からも繰り返し触れている
5. **ほぼ全曲で「育てていこうね」。** 完成品として渡すのではなく、披露を重ねてファンと仕上げるものとして扱っている。まなは約束!!!!!!! を「ぽっぱーのみんながいてこそ完成する曲」と書く
6. **振り付けの担当**（メンバーの投稿による）: 乙女ロック・シーソーゲーム＝くるみ（シーソーゲームのダンスパートはなつみが手伝い）。約束!!!!!!!＝メンバー全員（サビは主にまう）。
   メイク☆マイダンスは「ぽっぽ♪ポジティブ！！・始まりの宴!!!!!!! と同じ振付師さん」（まゆ）
