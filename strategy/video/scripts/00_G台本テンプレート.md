# 台本テンプレート（N4 掲示板掛け合い）

このファイルをコピーして `N4-XXX_<短い日本語名>.md` を作る。番号は連番。欠番を再利用しない。

型の仕様は `05_フォーマット定義/N4_掲示板掛け合い.md`、工程は `07_量産フロー.md` を見る。
**N3 のテンプレート（`00_台本テンプレート.md`）との違いは、構成表に「話者」列があること、
ブロックが 6 つあること、ライブ映像の指定欄があること、ループを 2 本管理すること。**
読みの注意・言い換え・キャプションの作り方は N3 と共通。

## 5 基準チェック（埋まらないなら台本にしない）

| 3 | **ペイオフ**（オチ） | 一言・一行動で言い切る |
| 4 | **予備知識** | 不要 / 「◯◯」を「△△」に言い換えれば不要 |
| 5 | **「最後に◯◯」の絵**（ループ 2） | 本編のオチとは**別に**、最後に見せる画があるか（別衣装・素の表情・ライブの決めカットなど）。**無いなら N3 に回す** |

## ループの管理（N4 の要）

**2 本張って 2 本とも回収する。**予告して出さないのは次から信用されないので禁止。

| | 張る位置 | 中身 | 回収位置 |
| --- | --- | --- | --- |
| **ループ 1** | 0–3s（伏せ字 ●● で） | | 22–30s（エピソード） |
| **ループ 2** | 0–3s（「最後に◯◯」） | | 30–35s（締め） |

**伏せ字は事実にだけ使う。**伏せた中身は必ず引用元の投稿に書いてあること。煽るためだけの伏せ字は使わない。

## 構成

**フックでオチを出さない。8 秒以上おなじ絵を出さない。**絵の切り替えは 3 / 9 / 14 / 22 / 30 秒。

| 区間 | 秒 | 話者 | 映像 | 字幕（15 字以内） | 台詞 |
| --- | --- | --- | --- | --- | --- |
| **フック** | 0–3 | 語り | 下記「フックの絵」 | | 伏せ字つきの属性提示 ＋「最後に◯◯」の予告。**名乗らない** |
| **ビジュアル** | 3–6 | 語り | 写真 | | |
| | 6–9 | **合いの手** | 同上 | | 視聴者の代弁（5〜12 字） |
| **開示** | 9–12 | 語り | 写真（別カット） | | 「実はアイドル」**ここで名前・あだ名を 1 回だけ出す** |
| | 12–14 | **合いの手** | 同上 | | 驚く（5〜12 字） |
| **ライブ映像** | 14–22 | 語り（短く） | **ライブ映像**（現場音を残す） | | 台詞は最小限。映像を見せる区間 |
| **エピソード** | 22–30 | 語り＋合いの手 | 投稿スクショ（出典を重ねる） | | **ループ 1 の回収**。自分の言葉の解説を必ず添える |
| **締め** | 30–35 | 合いの手 | 「最後に◯◯」の絵 | | **ループ 2 の回収**。ここで終わってループへ |

**上帯（全編固定）**: `ろりぽっぷ!!!!!!! ／ <あだ名>` を小さく常時表示。

**字幕は話者ごとに色と位置を変える**（例: 語り役＝画面中央・白／合いの手役＝やや下・黄）。
変えないと 2 人の会話に聞こえず、掛け合いの効果（注意のリセット）が消える。

### 語り口のチェック

| 見るところ | 判定 |
| --- | --- |
| 話者が 3〜8 秒ごとに交代しているか | 片方が 10 秒喋り続けたら掛け合いではない |
| 合いの手が 5〜12 字に収まっているか | 長いと 2 人目の語り役になってしまう |
| **方言を使っていないか** | VOICEVOX は標準語のイントネーションしか持たない。「〜やねん」は不自然に読まれる。**語尾を口語に寄せるだけ**にする |
| 合いの手が本人を貶していないか | 驚く側・感心する側に固定する。容姿の品定め・性的な茶化しは書かない |
| 掲示板の UI を再現していないか | レス番号・板名・アンカーは出さない。**採るのは掛け合いの構造だけ** |

### フックの絵

スクショは「エピソード」で初めて出し、ライブ映像は 14 秒からなので、**フックの 3 秒に映すものを別に用意する**。優先順に:

1. ユーザーが撮った写真がある → それを使う
2. 無ければ **`design.md` の色で作図**（ピンク `#d6006e` を基調に、話に合う色を 1 色足す）
3. それも難しければ**大きな文字だけの画面**。ただし Reels は文字中心の動画を減配するので、フック 3 秒に限る

### 出典の画面内表示の位置

**画面下部 400px は UI に潰される**（`src/safeArea.ts`）ので、出典は**エピソードブロックのスクショに重ねて**置く。
画面の最下部に置かない。
