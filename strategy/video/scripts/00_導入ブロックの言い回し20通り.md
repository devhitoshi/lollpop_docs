## 守るもの

- 合いの手役は**驚く側・感心する側**に固定。貶す・点数をつける・比較しない（型の禁止事項）
- **方言は使わない**（VOICEVOX は標準語のアクセントしか持たない）
- 字幕は**1 行 13 文字以内**（62px。超えると勝手に折り返されて崩れる）
- 合いの手は 5〜12 字、語りは 20 字前後
- 名乗りは**この 1 回だけ**。冒頭にも締めにも置かない。**言い方は固定**（下記「05 行の書き方」）
- **「地下アイドル」と言わない**（2026-09-05 オーナー判断。**この言い方を嫌がるメンバーが少なくない**ため）。
  基本は「アイドル」。説明が要る回だけ「ライブハウスで歌ってるアイドル」。キャプションのタグも `#ライブアイドル` に替える

#### 読みの落とし穴（実測）

**アルファベットは VOICEVOX がそのまま字母読みする。**

| 書き方 | 読まれ方 |
| --- | --- |
| `iLIFE` / `iLiFE!` | **アイエルアイエフイイ** ✗ |
| `アイライフ` | アイライフ ✓ |
| `tiktoker` | ティクトーカー ✓ |
| `ティックトッカー` | ティッ／ク／トッ／カー ✗（分割される） |
| `youtuber` | ユーチューバー ✓ |
| `読モ` | **ヨミモ** ✗ |

**`text`（読み上げ）と `subtitle`（字幕）を分ける**のが正解。
G3 は `text` に「アイライフの子？」、`subtitle` に「iLiFE!の子？」と書く。
**固有名詞は誤読ベイトに使わない**（`00_コメントを誘発する仕掛け.md` の鉄則）。

#### 使うときの注意

**他のグループ名は 1 本に 1 つまで。**続けて別のグループ名を出すと、
名前を借りて回遊を狙っているように見える。**同じグループ名を 5 本以内に再利用しない。**
挙げるのは**規模が近いか、それ以上のグループ**にする（格下として挙げると失礼になる）。
