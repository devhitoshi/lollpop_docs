## 構成

**フックでオチを出さない。**問いを立てて、最後まで引っ張る。**8 秒以上おなじ絵を出さない。**

| 区間 | 秒 | 映像 | 字幕（15 字以内） | ナレーション原稿 |
| --- | --- | --- | --- | --- |
| **フック** | 0–3 | ← **スクショは使えない**（状況で使うため）。下記「フックの絵」を参照 | | 問いを立てる。名乗らない |
| **状況** | 3–10 | 投稿スクショ | | |
| **展開** | 10–18 | | | **自分の言葉の解説**（引用が主にならないように） |
| **ペイオフ** | 18–23 | | | オチ |

**上帯（全編固定）**: `ろりぽっぷ!!!!!!! ／ <あだ名>` を小さく常時表示。
**動画内で名乗らない**（名前・プロフィールはキャプションに回す）。

### フックの絵（毎回ここで詰まるので先に決める）

スクショは「状況」で初めて出すので、**フックの 3 秒に映すものを別に用意する**。優先順に:

1. ユーザーが撮った写真がある → それを使う
2. 無ければ **`design.md` の色で作図**（ピンク `#d6006e` を基調に、話に合う色を 1 色足す）
3. それも難しければ**大きな文字だけの画面**。ただし Reels は文字中心の動画を減配するので、フック 3 秒に限る

### 出典の画面内表示の位置

引用条件で「出典を画面内に残す」と決めているが、**画面下部 400px は UI に潰される**（`src/safeArea.ts`）。
したがって出典は**状況ブロックのスクショに重ねて**（スクショの直下か上に小さく）置く。画面の最下部に置かない。
