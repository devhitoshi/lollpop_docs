## 型の仕様

| 項目 | 値 |
| --- | --- |
| 尺 | 30〜45 秒 |
| 冒頭 1 秒 | 数字の大きなテロップ（例: 「今週 5 本／新曲 1」）＋その週の写真 1 枚。ナレーションは 0.5 秒遅れて入る |
| 構成 | 0–2s 数字テロップ／2–10s 今週のライブ（会場名を並べる。1 会場 1 秒）／10–25s トピック 2〜3 個（初披露・アナウンス・メンバーの動き。各 5 秒・写真 1 枚＋テロップ 1 行）／25–35s 来週の予定（日付・会場）／35–40s 締め「詳しくは note の週刊まとめ」 |
| 字幕ルール | 常時。ナレーションの全文ではなく要点だけ（1 画面 20 字以内）。用語はそのまま。**写真を下地にして文字は画面の 1/3 以内**（文字だけの画面を作らない） |
| 音源 | **VOICEVOX** のナレーション＋ライブラリの BGM。話者は**未定**（ナレーション寄りの声から試聴して決める。E1 は情報動画なのでキャラを立てない）。**原曲は使わない**（記事の読み上げに原曲は要らず、権利面の変数を減らす）。固有名詞（曲名の「!」「♪」の数・メンバー名）はユーザー辞書に登録し、読みは人が試聴で確認する |
| 画角・比率 | 9:16、1080×1920。図版（セトリ・日程表）は `design.md` の色・書体（`#d6006e`・Noto Sans JP）に合わせる。Remotion のテンプレートで CSS を共有する |
| メッセージ | 「今週何があったか」を 40 秒で。1 本に詰めるトピックは 3 個まで（記事は 5〜6 見出しあるので削る） |
| キャプション・タグ | `#ろりぽっぷ` ＋ `@lollipop_1116`。キャプションに note 記事の URL。**「VOICEVOX:話者名」のクレジット表記を必ず入れる**（VOICEVOX の利用条件。入れ忘れたら投稿し直す） |

## 素材

| 項目 | 値 |

| 映像 | 自分で撮ったその週の写真（静止画は対バンでも全編 OK）。写真が無い週はテロップと図版だけで成立させる |
| テキストの切り出し元 | `articles/週刊まとめ/YYYY-MM-DD_YYYY-MM-DD.md` の見出し構成「今週のライブ」「初披露・新曲・アナウンス」「メンバーの動き」「来週の予定」をそのまま台本の節にする（「現場の反応」は他人の投稿の引用になるので動画には載せない）。公演データは `events/data_event.csv` |
| 更新頻度 | 週 1 本（週刊まとめ記事の公開に合わせる）。月刊まとめ（`articles/月刊まとめ/`）も同じ型で月 1 本 |

## 禁止事項

テンプレートの共通項目に加えて:

- 「現場の反応」節（ファンの投稿）を映像に載せない。要旨の引用も動画ではしない（記事では出典付きで可だが、動画は切り抜かれて出典が消える）
- TTS の声をメンバー本人に似せない（声質の指定・クローンは不可）。VOICEVOX にクローン機能はないので現状は自然に守られるが、ElevenLabs に乗り換えたときも同じ線を引く
- 「VOICEVOX:話者名」のクレジットを省いて投稿しない（利用条件。クレジット不要にするには 1 キャラ 40 万円＋税の別契約が要る）

## KPI と判定

| 項目 | 値 |
| --- | --- |
| 主指標 | 保存数＋シェア数（既存向けなので再生数より「手元に置かれるか」）。副指標: X での引用数、note 記事への流入 |
| 判定本数 | 4 本（1 ヶ月） |
| 採用基準 | 4 本の保存＋シェアの合計が、同期間の note 週刊まとめ記事の X での反応（いいね）を上回る |
| 廃止基準 | 4 本の保存数がいずれも 1 桁で、制作コスト（人の最終チェック時間）が 1 本 30 分を超え続ける |
