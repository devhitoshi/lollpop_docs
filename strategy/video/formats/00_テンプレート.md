# フォーマット定義テンプレート

縦動画の「型」を 1 型 1 ファイルで定義する。新しい型（自分で決めたもの・流行調査で見つけたもの）は、
このファイルをコピーして項目を埋めるだけで戦略に組み込める。台本・自動化パイプラインはこの定義を入力にする。

ファイル名は `<型ID>_<短い日本語名>.md`。型 ID の頭文字は対象層を表す:
`N` = 新規向け、`E` = 既存ファン向け、`X` = 実験（対象層未定）。番号は追加順で欠番を再利用しない。

---

## 基本情報

| 項目 | 値 |
| --- | --- |
| 型 ID | 例: A（A〜G は playbook 7.2 の番組表で確定済みの型。新規に見つけた型は下記の命名規則に従う） |
| 名前 | 例: X の反応集 |
| 状態 | 試行中 / 採用 / 廃止 のいずれか（廃止しても削除しない。再流行に備えて残す） |
| 対象層 | 新規・対バン回遊層 / 新規・現場未経験層 / 既存ファン / 未定 |
| 狙い | この型で視聴者に起こしたい行動を 1 つ（例: 公式 X をフォローする、次のライブ日程を見る、保存する） |
| 由来 | どの流行調査（`trend_YYYY-MM-DD.md` の何番）・どの検証結果から来た型か。自分で決めた型なら「自案 (日付)」 |
| 制作方式 | 手動 / 半自動 / 全自動（半自動＝台本と素材選びは人、合成は機械） |
| 投稿先 | TikTok（主）＋ Shorts / Reels 転載。転載しない場合は理由を書く |

## 型の仕様

| 項目 | 値 |
| --- | --- |
| 尺 | 例: 15〜21 秒（サビ 1 回分） |
| 冒頭 1 秒 | 何が映っているか（タイトルカード禁止。人の動き・音・文字のどれで掴むか） |
| 構成 | 秒単位で書く。例: 0–1s 動き出し / 1–3s 字幕でメッセージ / 3–15s 本体 / 15–18s 締めのテロップ |
| 字幕ルール | 常時 / 要点のみ / なし。1 画面あたりの最大文字数。用語の扱い（対バン等の専門用語を使うか） |
| 音源 | 原曲（ライブ音声そのまま） / プラットフォームの音源ライブラリ / ナレーション / 流行音源 |
| 画角・比率 | 9:16。安全域（上下の UI に字幕が被らない位置）を守る |
| メッセージ | 1 本 1 つ。この型が毎回伝える固定のメッセージがあれば書く |
| キャプション・タグ | 固定で付けるハッシュタグとメンション（現場ルール: 撮影動画には公式メンションを推奨） |

## 素材

| 項目 | 値 |
| --- | --- |
| 映像 | 何を使うか（自撮りのライブ動画・写真・図版・テロップのみ 等）と撮影条件（対バンは指定曲のみ動画可） |
| テキストの切り出し元 | `lollpop_docs` のパスと見出し。例: `guide/starter_pack.md` の「30秒でわかるろりぽっぷ!!!!!!!」 |
| 更新頻度 | この型を何本・どの周期で出すか（例: 週 1 本、ライブごと） |

## 禁止事項

`lollpop_docs/CLAUDE.md` の規約を継承する。型固有の禁止があれば追記する。

- 卒業メンバーの卒業後の活動・私生活に踏み込まない
- 運営の意図・体調・人間関係の推測を書かない
- メンバーの AI 生成画像・本人風 AI 音声を使わない
- 対バンでの指定曲以外の動画を使わない
- **「地下アイドル」と言わない**（メンバーに嫌がる人が多いため。ハッシュタグ `#地下アイドル` も使わない。2026-09-05 オーナー判断）
- 非公開データ（`lollpop_data` の投稿原文）を映像化しない。
  **例外（2026-09-03 改訂）: メンバー本人の公開投稿に限り、出典を画面に明示して引用できる**
  （条件は `F_メンバーエピソード.md` の「引用の扱い」を参照）。
  **ファン（第三者）の投稿も、playbook 7.3 の作法（許諾済み優先／@handle を消さない／文言を変えない／見た目で区別／ネガティブ不可）に従えば引用できる**
  （2026-09-07 改訂。それ以前は「メンバー本人の公開投稿に限る」としていた）

## KPI と判定

| 項目 | 値 |
| --- | --- |
| 主指標 | 例: 視聴完了率 / フォロワー外再生比率 / プロフィール遷移数 / 保存数 |
| 判定本数 | 何本出したら判定するか（例: 5 本） |
| 採用基準 | 例: 5 本の中央値で完了率 40% 以上、または 1 本でもフォロワー外再生 80% 超 |
| 廃止基準 | 例: 5 本すべて主指標がアカウント平均を下回る |
