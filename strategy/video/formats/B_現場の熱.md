### 型の仕様

| 項目 | 値 |
| --- | --- |
| 尺 | 15〜25 秒（サビ 1 回分＋前後 2 秒）。60 秒を超えない |
| 冒頭 1 秒 | サビ直前の「ぽ！ぽ！ぽ！ぽ！」の入りか、振りの動き出し。**タイトルカード・ロゴ・黒画面から始めない** |
| 構成 | 0–1s サビ直前の動き出し（客席のコールが聞こえる位置から）／1–3s 字幕 1 行「『ぽ！』って言うだけで参加できる曲」／3–18s サビ本体（字幕は消す。画面はステージだけ）／18–21s 締め字幕「ろりぽっぷ!!!!!!!／対バンで見かけたら『ぽ！』」 |
| 字幕ルール | 要点のみ・最大 2 枚。1 枚 20 字以内。対バン・特典会などの用語は**そのまま使う**（この層には通じる） |
| 音源 | **TikTok の音源ライブラリにある公式音源「ぽっぽ♪ポジティブ！！」を必ず当てる。** 2026-09-02 時点でこの音源には既に 989 件の投稿があり（他のろりぽっぷ曲は 1〜11 件）、音源ページが新規の入口として実在している。ここに並ばないと在庫に積めない。**ライブ音声（客席の「ぽ！」）は元動画の音量を残して重ねる** — 参加感はコールが聞こえることで伝わるので、公式音源だけにして無音にしない。重ねてテンポがずれて聞き苦しい場合は、判定 5 本のうち 2 本で「ライブ音声のみ」版を試して完了率を比べる（その版は音源ページに乗らない代わりに現場感が出る）。1 本目の投稿後 24 時間以内にミュート・Content ID の申し立てが無いか確認する |
| 画角・比率 | 9:16、1080×1920 以上。横撮り素材は使わない（縦で撮る）。字幕は画面下 20%〜上 15%・右 12% を避ける |
| メッセージ | 「初見でも参加できる」を毎回固定。曲名は字幕に入れない（曲名より参加のしやすさが刺さる層）。会場名だけはサビの上に 1 行（対バンは指定曲のみ撮れるので「どの現場か」が判断材料になる） |
| キャプション・タグ | `#ろりぽっぷ` `#ライブアイドル` `#対バン` ＋ `@lollipop_1116` メンション（`#fyp` `#おすすめ` は付けない）。曲名・会場名・日付をキャプションに書く |
| 転載 | CapCut の書き出しファイルを Shorts / Reels に直接上げる。**TikTok からダウンロードした透かし入りファイルを転載しない**（Instagram は透かし入りを減配・Meta 公式） |

| 項目 | 値 |

| 映像 | 自分で撮ったライブ動画。**対バンでは動画撮影が指定曲のみ**なので、指定曲がぽっぽ♪ポジティブ！！の公演、または主催・単独公演（全編可）で撮る。手ブレは許容、寄りを優先 |

### 禁止事項

テンプレートの共通項目に加えて:

- **「地下アイドル」と言わない**（メンバーに嫌がる人が多いため。ハッシュタグも不可）
- 他グループの出演者・客席の顔が判別できるカットは使わない（トリミングかぼかし）
- 卒業メンバーが映る過去素材は「在籍当時の記録」として扱い、現体制の紹介には使わない

### KPI と判定

| 項目 | 値 |
| --- | --- |
| 主指標 | 視聴完了率（TikTok アナリティクス）。副指標: フォロワー外再生比率、プロフィール遷移数、**音源「ぽっぽ♪ポジティブ！！」の総投稿数（基準値 989 件・2026-09-02）** |
| 判定本数 | 5 本（うち 3 本は公式音源＋ライブ音声重ね、2 本はライブ音声のみ。音源の当て方を比べる） |
| 採用基準 | 5 本の完了率の中央値が同時期の他型を上回る、または 1 本でもフォロワー外再生比率 80% 超 |
| 廃止基準 | 5 本すべてで完了率が自アカウント平均を下回り、かつ改善案（冒頭の差し替え）を 2 回試しても変わらない |
