# 検証ログ

データから出した提案（`当てはめ.md`）を、自分の投稿で確かめた記録。**採否はオーナーが決める。**エージェントは結果の表から下書きするだけ。
数字は `自アカウントの結果.csv`（TikTok Studio・YouTube Studio・Instagram インサイトから月 1 回転記）から取る。

## 書き方

```
### 仮説-NN 〈何を変えると、何がどうなるか〉
- 根拠: K-xxx
- やり方: 何を何本出すか（比べる相手も）
- 見る数字: 視聴完了率・平均視聴秒・フォロワー外再生の比率・プロフィール表示・保存・シェア
- 判定の基準: 例「3 本ずつ出して、フォロワー外の再生の中央値が 1.5 倍以上なら採用」
- 状態: 計画中 / 実施中 / 採用 / 不採用 / 保留
- 結果: （日付と数字）
```

## 仮説の一覧

### 仮説-01 H を 2 問・60 秒にすると、届く量が増える
- 根拠: K-001（1〜3 分は 1.9 倍）・K-002（15〜29 秒は 0.69〜0.77 倍）
- やり方: 同じメンバーの回で、いまの 1 問・25〜30 秒版と、2 問・55〜65 秒版を 1 本ずつ。題材を変えて 3 組
- 見る数字: フォロワー外の再生、平均視聴秒（60 秒版は完了率が下がって当然なので、**秒数**で比べる）、プロフィール表示
- 判定の基準: 3 組のうち 2 組以上で、60 秒版のフォロワー外の再生が 1.5 倍以上なら、H の標準を 60 秒にする
- 注意: 1 分以上は TikTok の収益化の条件で、データ上の強さは「慣れた投稿者が多い帯」だからかもしれない。だから自分で確かめる
- 状態: 計画中

### 仮説-02 「現場あるある」は、いまの型より届く
- 根拠: K-080（推し活 5.2 倍・アイドル 3.0 倍）・K-010（あるある 約 3.1 倍、日本全体の 7〜9 月）
- やり方: 試行中の型 X1 として 3 本（「地下アイドル」は使わない。悪口・運営批判にしない）
- 見る数字: フォロワー外の再生、シェア、コメント
- 判定の基準: 同じ月の A・F・H の中央値と比べて、フォロワー外の再生が上回れば続ける
- 状態: 計画中（型の追加はオーナー判断）

### 仮説-03 18〜19 時に出すと、昼に出すより届く
- 根拠: K-040
- やり方: 投稿時刻を 18〜19 時にそろえ、それ以前の投稿（時刻ばらばら）と比べる
- 見る数字: 投稿後 48 時間の再生、フォロワー外の比率
- 判定の基準: 5 本以上で中央値が上回れば標準にする
- 状態: 計画中

### 仮説-05 型 F の冒頭は「結果を問う」形のほうが「当てさせる」形より 3 秒で離脱されにくい
- 根拠: K-010（「結果」2.43 倍）・K-084（雑学で結論先出し 4.6 倍、推し活で問いかけ 2.2 倍）
- やり方: 型 F の企画 5 本（`claude-work/20261008_ショート動画専門家エージェント/試運転2_企画出し.md`。結果を問う 2 本・当てさせる 3 本）＋ F-001 を出し、型 F の検証記録で比べる
- 見る数字: 3 秒時点の離脱、視聴完了率
- 判定の基準: 3 本ごとの見直し（型 F の決まり）で、3 秒時点の離脱が少ないほうの形を次の 3 本に回す
- 状態: 計画中（企画の採否はオーナー）

### 仮説-04 焼き込んだ原曲はミュートされない
- 根拠: K-022（アイドルの曲を使った投稿の 15〜49% がミュート）
- やり方: H の 1 本目を投稿して、48 時間以内に音が残っているか・「音声が削除された」通知が来ないかを見る
- 判定の基準: ミュートされたら、旧ルール（公式音源を小さく重ねる。`lollpop_video/README.md` 型 H「投稿のルール」）に戻す
- 状態: 計画中
