## 30秒でわかるろりぽっぷ!!!!!!!

- **東京を拠点に活動する5人組のアイドルグループ**。2024年11月デビュー
- コンセプトは「**楽しさ無限大**」。かわいい曲とかっこいい曲、両方やります
- 月に14〜15本ライブに出ています。**2〜3日に1回はどこかのステージに立っている**計算
- ライブの9割は「対バン」（複数グループが出るイベント）。出番は20〜30分・5曲前後
- ライブのあとは「特典会」。**1,000円からメンバーと直接話せます**
- 初回は公式Xをフォローするだけで**写メ券が1枚無料**

この記事にずっと出てくる言葉です。ここだけ覚えれば以降は読めます。

## グループの基本

かわいい曲もかっこいい曲もやります。声を出して盛り上がってもいいし、後ろで静かに見ていてもいい。
写真を撮りに来る人もいれば、特典会だけ楽しみに来る人もいます。どれも正解です。

ろりぽっぷは、ゼロから集まったグループではありません。

急にかっこいい曲が混ざったりする。詳しくは楽曲の章で。

### 推しの決め方

決めなくても大丈夫です。というのが結論なのですが、それだと不親切なので少しだけ。

**1回目で決める必要はありません。** ライブを1本見て、目で追ってしまった人が推しです。
それでも決まらなければ「箱推し」（グループ全体を推す）という選び方があって、
これはこのグループではかなり多数派です。

もう少し能動的に決めたいなら、この順番が早いです。

1. Xで5人をフォローして1週間眺める（キャラの違いが一番はっきり出ます）
2. TikTokで動画を見る（動いているところを見ると印象が変わります）
3. ライブに1本行く
4. 特典会で気になった人と話す

4番まで行けばだいたい決まります。1,000円で決まるなら安いものです。

### ライブの「型」が読める3曲

さらに面白いのが、1曲目と最後の曲の傾向です。

- **1曲目に一番多いのが「ろりぽっぷ!!!!!!!」**（76回）
- **中盤の定番が「ぽっぽ♪ポジティブ！！」**（演奏された公演の約6割で中盤に登場）
- **締めの定番が「始まりの宴!!!!!!!」と「ろりぽっぷ!!!!!!!」**（それぞれ62回・64回）

つまりこの3曲を知っているだけで、**開幕・中盤・ラストの3点が読めます**。
初めてでも「あ、これで最後だ」が分かる。しかも都合のいいことに、
コール表が整備されているのもこの3曲です。予習するならここから。

## ライブに行く【準備編】

### いつどこでやっているか調べる

### 公演には4つのタイプがある

「で、どれに行けばいいの？」という話です。

**対バン**（全体の約9割）
複数グループが出るイベント。ろりぽっぷの出番は**20〜30分・5曲前後**です。
チケットはろりぽっぷではなく**イベントの主催者**から買います。
他のグループも見られて、値段も手頃。**最初の1回はこれが一番おすすめです。**

**単独ライブ Vol.○○**
ろりぽっぷだけのライブ。ほぼ月1のペースで開催されていて、記録では Vol.18 まで確認できます。
たっぷり見たいならこちら。

**ワンコインライブ**
500円で見られる公演。私服公演やコンセプト公演として単発で開かれます。入門にはこれ以上ない条件です。

**ワンマンライブ**
年に1〜2回の大きな公演。代官山UNIT → 赤羽ReNY alpha → 新宿ReNY と会場が大きくなっています。
フルセットで見られる特別な日です。

### チケットの取り方

対バンなら、イベント主催者のチケットページ（LivePocketなどが多い）から購入します。
TimeTreeや公式Xの告知にリンクが貼ってあるので、そこから辿るのが確実です。

当日券がある公演も多いので、思い立った日に行くこともできます。

### お金の話

初回にいくらかかるか、正直に書いておきます。

| 項目 | 目安 |
|---|---|
| チケット | 対バンはイベントによる。ワンコインライブなら500円 |
| ドリンク代 | 500〜600円（多くのライブハウスで別途必要） |
| チェキ券 | 1,500円（トーク・サイン付き） |
| 写メ券 | 1,000円（トークあり） |

ここで朗報です。**初めての方は、公式Xをフォローするだけで写メ券が1枚無料になります。**
つまり最初の1回は、チケット代とドリンク代だけでメンバーと話せます。

### 持ち物

**手ぶらで大丈夫です。**

ペンライトやサイリウムは、あると楽しいですが必須ではありません。
持っている人は推しの担当カラーに合わせています（赤・黄・水色・緑・白）。
なくても誰も気にしません。

強いて言えば、現金は少し多めに。特典会でチェキを追加したくなることがあります。

## ライブ当日【会場編】

初めてだと、会場に着いてからの流れが分からなくて不安だと思います。順番に書きます。

### 当日の流れ

1. **会場に着く** — 対バンなら開演の少し前で十分。整理番号順に入場します
2. **受付でドリンク代を払う** — ドリンクチケットをもらって、バーカウンターで飲み物と交換
3. **フロアに入る** — 好きな場所で待ちます
4. **ろりぽっぷの出番** — 20〜30分、5曲前後
5. **物販・特典会** — 出番のあと、指定の場所に列ができます

### どこで見ればいいか

**後ろで大丈夫です。**

ろりぽっぷがよく出るのは、浅草VAMPKIN、アイドルステージ新宿、GARRET udagawa、SHIBUYA CYCLONE
といった100〜300人規模のライブハウス。**後ろのほうに立ってもステージまで数メートル**です。
最前に行かないと見えない、ということはありません。

前方は常連の方が固まっていることが多いので、最初は後方から様子を見るのが気楽です。
慣れてきたら好きな場所へどうぞ。

#### 途中から入っても、途中で帰ってもいい

対バンは何組も出るので、**目当てのグループの出番だけ見て帰る人は普通にいます。**
一日中いる必要はまったくありません。

逆に、時間があるなら他のグループも見てみると発見があります。それも対バンの楽しみです。

## ライブを楽しむ【コール編】

### まず、コールは義務ではありません

大事なことなので最初に書きます。

**腕を組んでじっと見ている人も普通にいます。** 声を出さなくても、手を叩かなくても、誰も気にしません。
ライブ中に写真を撮っているだけの人もいます。全部OKです。

「楽しさ無限大」というのは、こういうことです。楽しみ方が強制されない。
なので以下は「やってみたくなったら」の話として読んでください。

### 覚えるのは3曲でいい

ファンがまとめている[コール表](../songs/call_list.md)には26曲分の枠がありますが、
**中身が書かれているのは3曲だけ**です。残りは現在整備中。

でも、これで困りません。その3曲というのが、
**演奏回数の1位・2位・3位そのもの**だからです。ここを押さえれば、どのライブでも参加できる場所があります。

| 曲 | 難易度 | 初見でどうするか |
|---|---|---|
| ぽっぽ♪ポジティブ！！ | ★☆☆ | **初見で参加できます。**「ぽ！」と言うだけ |
| 始まりの宴!!!!!!! | ★★☆ | 「ソイヤッ！」を真似する。落ちサビは見ているだけでOK |
| ろりぽっぷ!!!!!!! | ★★★ | メンバーがその場で指示を出す箇所があります |

#### ぽっぽ♪ポジティブ！！ — 最初の1曲

イントロで「ぽっ！ぽ！ぽ！ぽっ！ぽ！」、サビでも「ぽ！ぽ！ぽ！ぽ！」。
**「ぽ」と言っているだけ**です。リズムに合わせるだけなので、初見でも入れます。

一番よく演奏される曲でもあるので、練習の効率が最高にいい。まずこれだけ覚えて行きましょう。

#### 始まりの宴!!!!!!! — 「ソイヤッ！」の曲

和テイストの曲で、イントロから「ソイヤッ！ソイヤッ！ソイヤッ！」の連呼が始まります。
掛け合いもあって、

> 和太鼓だ！（オイ！）ドンドコドン！（オイ！）今日は宴だ騒ごうぜ！（オイ！）

というコール＆レスポンスが入ります。周りが「オイ！」と言うので、真似すれば大丈夫。

途中に「サークルを作って盆踊り」という振り付けパートや、落ちサビにメンバーを順番に呼ぶ
「ケチャ」があります。ここは難しいので、最初は見ているだけで十分です。

#### ろりぽっぷ!!!!!!! — 覚えなくていい曲

看板曲ですが、実は初見のハードルが一番高い曲です。
理由は、**Bメロと間奏でメンバーがその場で指示を出す**から。内容は毎回変わります。

でもこれ、裏を返せば**覚えなくていい設計**ということです。
その場でメンバーが「こうやって！」と教えてくれるので、従えばいい。
むしろ予習しようがないので、気楽に行きましょう。

### コール表を読むときの注意

コール表を開くと、こんな言葉が説明なしで出てきます。

| 言葉 | 意味 |
|---|---|
| **MIX** | 曲の合間に入れる定型の掛け声。「スタンダード」「ジャパニーズ」「アイヌ」など種類があります |
| **ファイボー！パン！ワイパー！** | MIXの中に出てくる決まり文句。周りが言うので合わせれば大丈夫 |
| **ケチャ** | メンバーに向かって手をかざす動作 |
| **振りコピ** | メンバーの振り付けを真似すること |
| **ガチ恋口上** | サビ前などに入れる、決まった長ゼリフ |
| **メンバーコール** | メンバーの名前を呼ぶパート |

そしてもう1つ、**重要な注意**があります。

コール表の**メンバー名の部分は、卒業した2人の名前が残ったまま**になっています。
「なつみ・あみ」「おひめの指示に従う」といった記述がそれです。
名前を呼ぶパートは今のメンバーに変わっているので、**周りに合わせてください。**
間違って卒業したメンバーの名前を呼んでしまわないように。

### 撮影のルール

ろりぽっぷは撮影にかなり寛容です。ただし公演の種類で変わります。

- **対バンイベント** — 静止画は全編OK。**動画は指定曲のみ**
- **主催ライブ（ワンマン・単独）** — 静止画も動画も全編OK

撮った写真や動画はSNSに上げてOKです。その際はハッシュタグやメンションを付けると喜ばれます。
対バンの動画制限だけ気をつけてください。

#### 衣装でセトリが読める

小ネタですが、当日の衣装で曲の傾向が読めます。

- **お祭り衣装（宴衣装）** — かわいい系のセットリストが多め
- **黒衣装** — かっこいい系が多め

会場に入って衣装を見たら「今日はどっち系かな」と予想してみてください。
歴代の衣装は [アー写履歴](../members/artist_photos.md) で見られます。

## 特典会に行く

ライブが終わったら特典会です。ここがろりぽっぷの一番おいしいところかもしれません。

### 券の種類と料金

| 券種 | 料金 | 内容 |
|---|---|---|
| **チェキ券** | 1,500円 | ツーショットのチェキ＋トーク＋サイン |
| **写メ券** | 1,000円 | スマホでのツーショット＋トーク |

- チェキ券2枚で、15秒の動画に変更できます
- **新規特典**: 公式Xをフォローすると写メ券が1枚無料
- 12,000円以上購入すると写メ券が1枚もらえます

**注意: 外部主催のイベントでは、この券が使えないことがあります。**
そのイベント専用のチケットを買う方式に切り替わり、料金も枚数の考え方も変わります。
（例: 2026年8月30日「バブリー革命ライブ＠カモガワ」は専用チケット1枚で写メ、2枚でサイン入りチェキ）
どちらの方式かは当日の公式Xで告知されるので、対バンに行く前は一度見ておくと安心です。

### 特典会の流れ

1. 物販で券を買う
2. 話したいメンバーの列に並ぶ
3. 順番が来たら、撮影して、その間に話す
4. チェキならその場で写真を受け取る

**券を買ったら早めに列に並んでください。** 列が途切れると終了になることがあります。

### 何を話せばいいか

これが一番の不安だと思います。結論から言うと、

**名前を言って「初めて来ました」だけで十分です。**

本当にこれで成立します。それでも間が持たない気がするなら、この記事の
メンバー紹介で書いたネタを使ってください。

- **やぎくるみ** → 群馬の話
- **夏川茉夢** → 餃子と静岡
- **まう** → グミ
- **松川愛美** → その日のライブの感想
- **愛月まな** → 猫

撮ったチェキはSNSに上げてOKです。グループのタグは `#ろりぽっぷ`。

さらに、**メンバーごとにファンが使っているタグ**があります。推しのタグを添えると、
同じ現場にいた人の投稿とつながりますし、本人にも見つけてもらいやすくなります。

| メンバー | タグ |
|---|---|
| やぎ くるみ | `#くるみるく` |
| 夏川 茉夢 | `#餃子のおまゆ` |
| まう | `#まうだよ` |
| 松川 愛美 | `#まんてんあみてん` |
| 愛月 まな | `#まなてぃータイム` |

### やってはいけないこと3つ

ルールはいろいろありますが、初めての人が踏みやすいのはこの3つです。

1. **メンバーの体・衣装・髪に触れない**
2. **連絡先を渡さない、聞かない**
3. **スマホの画面を見せながら話さない**

他にもルールはあるので、一度[ルール・マナー](./rules.md)に目を通しておくと安心です。
とはいえ、普通にしていれば普通に楽しめます。構えすぎないでください。

#### プレゼントについて

手紙やプレゼントは受け付けています。運営スタッフに渡す形です。

ただし受け取れないものがあります。開封済みのもの、現金や金券、危険物、生き物、なま物（花はOK）、下着類。
詳しくは[ルール](./rules.md)を確認してください。

メンバーのAmazonほしいものリストから贈ることもできます。リンクは[リンク集](./link.md)に。
